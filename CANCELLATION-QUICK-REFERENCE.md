# 📋 Quick Reference: Top-Up Cancellation

## When to Use

Cancel a top-up transaction when:
- ✅ Customer changes their mind
- ✅ Wrong amount was entered
- ✅ Student's card is not working
- ✅ Customer walks away before tapping
- ✅ System shows an error
- ✅ Customer takes too long to tap card

## How to Cancel

### Step-by-Step:

1. **During "TAP CARD NOW" Screen**
   - You'll see a red "CANCEL" button at the bottom
   
2. **Click the CANCEL Button**
   - A popup window will appear
   
3. **Select a Reason**
   - Choose from the dropdown menu, OR
   - Select "Other" and type your own reason
   
4. **Click "Confirm Cancellation"**
   - Transaction will be cancelled
   - You'll see a confirmation message
   
5. **Done!**
   - Modal closes automatically
   - You can start a new top-up

## Common Reasons (Quick Pick)

| Reason | When to Use |
|--------|-------------|
| Customer changed mind | Student decides not to reload |
| Wrong amount entered | Made a mistake typing amount |
| Card not working | RFID card won't read/scan |
| Customer left | Student walked away |
| System error | Technical problem occurred |
| Timeout | Customer took too long |
| Other | Any other situation (type reason) |

## Important Notes

⚠️ **Required:** You MUST select a reason - you cannot cancel without one

📝 **Logged:** All cancellations are recorded for audit purposes

🔒 **Final:** Once cancelled, the transaction cannot be recovered

⏱️ **Quick:** Select common reasons quickly from dropdown

## Custom Reason

If you select "Other (specify below)":
- A text box will appear
- Type your reason (max 200 characters)
- Be specific but concise
- Example: "ATM withdrawal failed, student has no cash"

## What NOT to Do

❌ Don't close the browser/tab to cancel  
❌ Don't refresh the page to cancel  
❌ Don't just walk away from the screen  
❌ Always use the CANCEL button properly  

## What Gets Logged

When you cancel, the system records:
- ✓ Your name (cashier)
- ✓ The amount
- ✓ The reason you provided
- ✓ Date and time
- ✓ Transaction ID

This helps track patterns and improve service!

## Need Help?

If you're unsure which reason to select:
- Choose the one that best matches the situation
- When in doubt, use "Other" and explain briefly
- Ask your supervisor if you need guidance

They are NOT used to penalize staff for legitimate cancellations!
